1. **AI Werewolf** — each player gets a durable-actor agent (secret role, persistent memory) that schemes with others over Agent Relay; judges watch a live game of social deduction unfold in the demo — hilarious, undeniable use of both techs, zero dead air on stage.
2. **Haunted Mansion** — each room is a Durable Actor holding puzzle/scare state, ghost agents roam room-to-room coordinating jump-scares via Agent Relay while humans play live — on-theme for Halloween, visually fun, judges can walk through it themselves.
3. **Self-organizing software factory** — a pool of coder agents, each a durable actor with long-running build state, negotiate task splits over Agent Relay and ship a small feature live — most technically impressive ("scale to millions" bait) but riskiest to pull off cleanly in a 5-min demo.
